# List of additional feature repositories

## Tmux Plugin Manager (TPM)
**Source**: [tpm (Github)](https://github.com/tmux-plugins/tpm)
**Author**: [tmux-plugins](https://github.com/tmux-plugins)
**Clone**: `git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm`
Installs and loads tmux plugins.
Tested and working on Linux, OSX, and Cygwin.
